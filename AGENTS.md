# AGENTS.md — MedicAI

AI agents working on this repo: read this before touching anything.

## What this project is

Offline combat medic AI triage assistant. No cloud. No signal required.
Hardware: Pi 4 (WiFi hotspot + speaker) + M3 MacBook (all AI inference) + iPhone (camera).
Pipeline: FastVLM wound vision → Whisper STT → Meditron-7B triage reasoning → Piper TTS.

## Folder structure

```
mac/           Partner's FastVLM setup. DO NOT modify without coordinating.
  setup.sh     Creates mac/venv, downloads FastVLM MLX checkpoints
  smoke_test.py  FastVLM inference test + schema validation
  schema.json  Contract between FastVLM and Meditron. Schema changes = breaking change.
  model_names.json  Auto-generated by setup.sh. Maps "0.5B" -> HF repo name.

pi/
  hotspot_setup.sh  Run on Pi to create "MedicAI" hotspot + SSH key setup

assets/
  gsw_demo.jpg  REQUIRED for demo. Not in git (binary). Drop it manually before demo.

vision.py      FastVLM wrapper. Outputs schema.json-compatible dict + natural language desc.
stt.py         Whisper tiny. Records mic or transcribes a WAV file.
meditron.py    Ollama Meditron-7B. Streams response, parses CLASS ID, DB lookup fallback.
tts.py         Piper TTS. SSH-pipes raw PCM to Pi speaker. Local afplay fallback on Mac.
main.py        Orchestrator. Loads all models once, then loops on ENTER trigger.
procedures.json  12-class triage DB with condition-specific cautions.
requirements.txt  All Python deps. Install into mac/venv.
```

## Dev environment

All Python runs in `mac/venv`. Activate before any command:

```bash
source mac/venv/bin/activate
```

Setup from scratch:

```bash
# 1. FastVLM + mlx-vlm + model download (~3-5 GB, takes ~5 min)
cd mac && bash setup.sh && cd ..

# 2. STT + TTS + networking deps
pip install -r requirements.txt

# 3. Ollama + Meditron
#    Install Ollama: https://ollama.com/download
ollama serve &
ollama pull meditron

# 4. Pi hotspot (on the Pi)
sudo bash pi/hotspot_setup.sh
```

## How to run

```bash
source mac/venv/bin/activate

# Full pipeline (requires Ollama running, gsw_demo.jpg in assets/)
python main.py

# Vision only test
python vision.py --image assets/gsw_demo.jpg

# STT only test
python stt.py --duration 5

# Meditron only test
python meditron.py --medic "GSW upper thigh, heavy bleeding, sickle cell"

# TTS only test
python tts.py --text "Apply tourniquet two inches above the wound." --local
```

## Critical constraints agents must respect

1. **mac/schema.json is a cross-team contract.** Do not change field names, enum values, or required fields without updating both `vision.py` (PROMPT) and `meditron.py` (format_response).

2. **Meditron context window = 2048 tokens.** The few-shot prompt in `meditron.py:FEW_SHOT_TEMPLATE` must stay under ~300 tokens. Do not add more examples. Test with `len(prompt)`.

3. **mac/model_names.json is auto-generated.** Do not commit it. It's in .gitignore. Regenerate with `cd mac && bash setup.sh`.

4. **assets/gsw_demo.jpg is not in git.** Never commit it. JPEG of wound prop must be added manually before demo.

5. **SSH to Pi must be key-based.** Password prompts during demo = demo fails. Test with `ssh pi@192.168.4.1 echo ok` before presenting.

## Testing

```bash
# Smoke test FastVLM
python mac/smoke_test.py --image mac/test_images/sample.jpg

# Smoke test full pipeline (demo scenario, no real mic/speaker)
SKIP_VISION=0 DEMO_IMAGE=assets/gsw_demo.jpg USE_PI_SPEAKER=0 python main.py
# Then press ENTER — it will try to record from mic; use --file for a pre-recorded WAV

# Meditron standalone (fastest feedback loop)
python meditron.py --medic "GSW upper thigh heavy bleeding sickle cell"
```

## Environment variables

| Variable | Default | Description |
|---|---|---|
| `RTSP_URL` | None | iPhone RTSP stream (e.g. rtsp://192.168.4.x:8554/video) |
| `DEMO_IMAGE` | assets/gsw_demo.jpg | Override fallback image path |
| `SKIP_VISION` | 0 | Set to 1 to bypass FastVLM entirely |
| `USE_PI_SPEAKER` | 1 | Set to 0 to play audio locally on Mac |
| `RECORD_SECS` | 8 | Mic recording duration |
| `PI_HOST` | 192.168.4.1 | Pi's IP on MedicAI hotspot |
| `PI_USER` | pi | Pi SSH user |
| `PIPER_VOICE` | en_US-lessac-medium | Piper voice model |

## PR instructions

- All code must run offline. No `requests` calls to external URLs except `localhost:11434` (Ollama).
- Do not add new Python packages without updating `requirements.txt`.
- Schema changes require coordinated updates across `mac/schema.json`, `vision.py` PROMPT, and `meditron.py` format_response. Call this out explicitly in the PR.
- Test the demo scenario end-to-end before merging: medic says "GSW upper thigh, sickle cell" and system speaks condition-aware steps.
